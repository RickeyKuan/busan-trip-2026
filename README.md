# BUSAN, SLOWLY — 釜山旅行誌 2026

A responsive, interactive Busan trip microsite for 2026/12/17–12/20.

## Features
- GSAP + ScrollTrigger motion design
- Day-by-day interactive itinerary
- Google Maps links for key stops
- Packing and Olive Young checklists (saved in browser localStorage)
- Responsive layout and reduced-motion support

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then Save.
4. Wait for the Pages deployment to finish. The site URL will be:
   https://rickeykuan.github.io/busan-trip-2026/

GSAP is loaded from jsDelivr CDN. Google Fonts are loaded from Google Fonts.
